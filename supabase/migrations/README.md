# Historical migration archive

This directory contains Adesse's historical database migrations. These files are retained strictly as documentation, historical records, and reference materials for reconstructing the database's development and architecture.

**Never modify, delete, rename, reorganize, or use this directory as the destination for new migrations. Do not add any new migration files here.**

All future database rebuilds and baseline SQL scripts must be placed exclusively in [`../rebuild/`](../rebuild/). The historical migrations remain reference materials for the new consolidated database architecture; they are not the execution package for a fresh project.
